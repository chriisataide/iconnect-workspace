# iConnect Workspace — dependências de execução.
#
# Curto de propósito, e o tamanho é um resultado e não uma meta: o código do
# Workspace não importa nenhuma biblioteca de terceiros. Só Django e stdlib.
# Foi assim que ele foi escrito desde a primeira onda, e é o que permite este
# arquivo caber numa tela.
#
# O requirements do projeto anterior tinha 57 entradas — DRF, Celery, Axes,
# compressor, storages, JWT, nltk. Nenhuma delas é usada aqui.
#
# ## A exceção, e por que ela é uma
#
# `reportlab` entrou para gerar o PDF dos relatórios de campo (§34–36). Foi uma
# decisão pedida e tomada de olhos abertos, não um efeito colateral.
#
# A alternativa era `weasyprint`, que converte HTML+CSS e daria um documento
# mais parecido com a tela. Ela foi recusada pelo DEPLOY: weasyprint exige
# Cairo, Pango e GDK-PixBuf instalados no sistema operacional — bibliotecas C
# que precisam entrar na imagem, versionar junto e quebrar quando a base muda.
#
# `reportlab` é Python puro: instala por wheel, não pede nada do sistema, e a
# mesma imagem que roda o Django roda o PDF. O preço é desenhar o layout em
# código em vez de em CSS — pago uma vez, em `services/pdf.py`.

Django==6.0.8

# `sqlparse` é dependência transitiva do Django e está PINADA aqui de
# propósito. A auditoria de segurança de agosto de 2026 achou quatro CVEs
# abertas na 0.5.5, que era a versão que o resolvedor trazia — e dependência
# transitiva não aparece em `requirements.txt`, então ninguém olha para ela.
# Pinar é o que faz a próxima auditoria enxergá-la.
sqlparse==0.6.0

# Banco de produção. Em desenvolvimento e teste é SQLite, que vem com o Python.
psycopg2-binary==2.9.12

# Cache de produção (`django.core.cache.backends.redis.RedisCache`). Não é
# importado por código nosso — é infraestrutura, escolhida em settings/prod.py.
redis==8.1.0

# Servidor WSGI de produção.
gunicorn==26.0.0

# PDF dos relatórios de campo. Python puro — ver a nota no topo deste arquivo
# sobre por que não é weasyprint.
reportlab==5.0.0
openpyxl==3.1.5

# Foto de perfil. `ImageField` do Django não funciona sem Pillow — ele valida
# que o arquivo é mesmo uma imagem na hora de salvar, e sem a biblioteca o campo
# nem passa no `check`. Também é o que os testes de ícone usam para conferir que
# o favicon é quadrado e que o apple-touch não tem transparência.
Pillow==12.3.0
