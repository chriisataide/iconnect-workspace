Não é limitação a contornar, é proteção. A casca lê o banco em cada carregamento — trilho, sino, assistente. Uma página de erro que precisa consultar o banco para ser desenhada é uma página de erro que falha justamente quando o banco é o problema, e aí o visitante recebe o "A server error occurred." cru do Django. Por isso aqui não há `{% templatetag openblock %} url %}` para rota com argumento, nenhuma variável de contexto, nenhuma consulta. Só HTML e dois ``.
